DARKSYNC V2 — локальная стартовая платформа
===========================================

ЧТО ЕСТЬ
- Тёмный интерфейс с фиолетовым свечением.
- Регистрация и вход.
- SQLite база данных, создаётся автоматически.
- Каталог конфигов и поиск.
- Административная панель.
- Добавление конфигов и загрузка файлов.
- FREE/PREMIUM-метки и ограничение доступа к Premium-файлам.
- Локальный демонстрационный режим подписки для проверки интерфейса.

ВАЖНО
Это стартовый проект для локального тестирования, а не готовый публичный коммерческий сервис.
Реальные платежи НЕ подключены. Кнопка демонстрационной активации Premium работает только локально.
Перед публикацией в интернете нужно настроить HTTPS, безопасные сессии, секреты окружения,
резервное копирование, лимиты загрузки, проверку файлов, политику конфиденциальности и платёжного провайдера.
Не загружай сюда личные или опасные файлы. Используй только файлы, на распространение которых у тебя есть права.

ЗАПУСК НА WINDOWS 11
1. Установи Node.js LTS с официального сайта https://nodejs.org/
2. Распакуй архив в обычную папку, например Рабочий стол\DARKSYNC-V2.
3. Открой папку и дважды нажми start-windows.bat.
4. При первом запуске дождись установки зависимостей (нужен интернет).
5. Открой браузер и перейди на http://localhost:3000

ПЕРВЫЙ АДМИНИСТРАТОР
При первом запуске открой страницу регистрации и создай аккаунт.
Чтобы назначить аккаунт администратором:
1. Останови сервер в чёрном окне сочетанием Ctrl+C.
2. Открой файл server.js и найди строку:
   const ADMIN_EMAIL = (process.env.ADMIN_EMAIL || '').toLowerCase();
3. Самый простой вариант — при запуске задать ADMIN_EMAIL, но для новичка:
   открой cmd в папке проекта и выполни:
   set ADMIN_EMAIL=твой_email_при_регистрации
   npm start
   (если используешь start-windows.bat, сначала закрой его и запускай команды через cmd).
4. Перезапусти сервер и войди этим аккаунтом. Админ-права проверяются по email из настройки.

Если хочешь настроить администратора проще, в начале server.js можно изменить значение
ADMIN_EMAIL на адрес, который использовал при регистрации, например:
const ADMIN_EMAIL = (process.env.ADMIN_EMAIL || 'you@example.com').toLowerCase();
Заменяй you@example.com на свой email. Не публикуй этот адрес в скриншотах.

ЛОКАЛЬНОЕ ХРАНЕНИЕ
База данных и загруженные файлы создаются в папках data и uploads. Не удаляй их, если хочешь
сохранить аккаунты и конфиги.

Подписка и безопасность
- Не вводи данные банковской карты: платежи не реализованы.
- Не публикуй сайт с настройками для локального запуска без дополнительной защиты.
- Если тебе ещё нет 18 лет, попроси родителя/опекуна помочь с платёжными аккаунтами, договорами и публичным запуском.
